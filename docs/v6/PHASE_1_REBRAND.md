# AntigoStack V6 Phase 1 — Identity Rebrand

## Purpose

Phase 1 changes the current project identity from CodexForge to AntigoStack without pretending that the V5 runtime has already become vendor-neutral.

## Identity

- Project: **AntigoStack**
- Tagline: **Adaptive Engineering Intelligence for AI Agents**
- Development generation: **V6**
- Historical lineage: **CodexForge V1-V5**
- Currently verified runtime: **CodexForge V5.0.1 on OpenAI Codex**

## Scope

This phase updates current public branding, current project-facing documentation, evaluation/repository tool display names, and the CI concurrency-group identifier.

It deliberately preserves `.codex/`, `.agents/`, `~/.codex-engineering-system/`, the V5 manifest/installer identity, the `codexforge-v5` evaluation condition, the Phase 0 baseline, historical V1-V5 materials, and technically correct OpenAI/Codex references.

## Evidence rule

AntigoStack V6 is described as being developed toward a vendor-neutral architecture. The repository must not claim verified Claude Code, Gemini CLI, Copilot, or other runtime support until adapters exist and portability verification passes.

## Next phase

After this rebrand is merged, the next planned phase is agent-ecosystem research and architecture specification. Runtime-path migration and provider-neutral adapter work remain separate later phases.
