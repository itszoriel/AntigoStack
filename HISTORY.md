# Project History

CodexForge evolved through six preserved engineering-system snapshots before its public repository was prepared.

The Git history for **v1.0.0 through v5.0.0-prepublic** was reconstructed from those preserved snapshots. The commits preserve the real milestone order and the dates of the archived artifacts; they are **logical milestone commits**, not a claim that every experimental edit originally happened as a Git commit.

## Milestones

- **v1.0.0** — initial Codex engineering skills framework.
- **v2.0.0** — broader production, security, accessibility, AI, automation, and specialist coverage.
- **v3.0.0** — major expansion across languages, frameworks, cloud, data, games, creative tooling, security, infrastructure, and enterprise technology.
- **v4.0.0** — compact 18-core architecture, specialist library, packs/profiles, routing, and context-budget controls.
- **v4.1.0** — VB.NET, WinForms, WPF, and legacy .NET modernization specialization.
- **v5.0.0** — professional-intelligence architecture: truth over agreement, evidence levels, manual handoff, version awareness, deeper professional playbooks, deployed-runtime verification, and Git/release discipline.

From the public repository onward, normal Git history should be recorded directly as development occurs.
