# Project history

## Provenance

CodexForge reached its public-repository preparation through six preserved project snapshots. The history from `v1.0.0` through `v5.0.0-prepublic` was reconstructed from those snapshots, followed by a separate public-preparation commit.

These are logical milestone commits, not a claim that every original development edit happened in Git. Their timestamps record the preserved artifact chronology used for reconstruction; they should not be interpreted as a complete development timeline.

The imported Git bundle was verified as a complete history. It contains seven linear commits and seven annotated tags. Each reconstructed tag retains provenance language in its annotation.

## V5.0.1 working milestone

V5.0.1 corrects Windows PowerShell 5.1 installer parsing, makes `-WhatIf` side-effect free for V5-managed directories, and adds PowerShell parser and ASCII-safety regression checks. The current public-preparation work also adds expanded architecture and operating documentation, evaluation scenarios, repository QA, and CI.

V5.0.1 is not represented as a historical tag or GitHub Release in the imported bundle. It should receive a normal new commit after local verification; a tag or release should be created only if the owner intentionally declares a distributable V5.0.1 milestone.

From this point forward, ordinary development should be recorded directly as it occurs rather than reconstructed later. See [CHANGELOG.md](CHANGELOG.md) for the package change record.
