# Manual User Action / Handoff

Use when a required step crosses an account, permission, MFA, GUI, legal/business, hardware, signing, secret, production, registrar, app-store, or unavailable-tool boundary.

Provide:

1. what the agent completed
2. what remains manual
3. why it must be manual
4. numbered steps matched to OS/tool/version
5. exact verified values/paths/commands/labels where known
6. expected result
7. verification method
8. troubleshooting for non-trivial flows
9. rollback/recovery for risky actions
10. exact resume point

Never invent current UI labels. If documentation/version was not verified, state the uncertainty and describe the stable concept the user should locate.
