# creative-3d-dcc-production

**Category:** Creative / 3D / Design

## Purpose

Production workflows across Maya, 3ds Max, Houdini, Blender-adjacent DCC tools, Substance-style texturing, interchange, naming, units, topology, rigs, procedural networks, and engine/VFX handoff.

## Activate When

- creative or 3D production task matches this workflow
- handoff between design/DCC and engineering
- asset optimization/export/licensing matters

## Required Workflow

1. Identify target medium/platform and editable source format.
2. Define units, dimensions, naming, color/material, and export requirements.
3. Preserve nondestructive/editable source.
4. Track asset provenance/licensing.
5. Check accessibility/readability when user-facing.
6. Test export/import in the destination tool/runtime.
7. Measure file size/runtime performance when relevant.

## Must Not

- destroy editable source without backup
- assume assets are licensed because downloadable
- change visual brand without requirement

## Expected Outputs

- production-ready asset/design workflow
- export/handoff specification
- licensing/provenance notes
- quality/performance checks
